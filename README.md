# تندرو (Tondro)

مدیر دانلود فارسی، سریع و مینیمال برای Android با Flutter.

## قابلیت‌ها

- دانلود واقعی HTTP/HTTPS
- Pause / Resume
- Queue و دانلود هم‌زمان قابل تنظیم
- Retry و Auto-Resume
- دانلود پس‌زمینه Android
- اعلان پیشرفت، توقف، خطا و پایان
- Wi-Fi only
- محدودیت سرعت واقعی
- Scheduler
- تشخیص لینک Clipboard
- دریافت لینک با Share از مرورگر و برنامه‌های دیگر
- تاریخچه محلی دانلودها
- سرعت لحظه‌ای و زمان باقی‌مانده
- دسته‌بندی خودکار تصویر، ویدیو، صوت، سند، آرشیو و APK
- پوشه جدا برای هر دسته
- فیلتر و مرتب‌سازی
- بازکردن فایل تکمیل‌شده
- حذف دانلود و فایل
- تم سیستم / روشن / تیره
- رابط فارسی RTL و Material 3

## حریم خصوصی

تندرو برای مدیریت دانلودها به اینترنت دسترسی دارد. تشخیص Clipboard قابل خاموش‌کردن است و پردازش لینک به‌صورت محلی انجام می‌شود. داده دمو یا تست در رابط برنامه قرار داده نشده است.

## توسعه

```bash
flutter pub get
flutter test
flutter analyze
flutter run
```

برای Android، GitHub Actions پروژه پلتفرم Android را با `tool/bootstrap_android.sh` تولید و APK آزمایشی را Build می‌کند.

## وضعیت انتشار

پروژه هنوز در مرحله آماده‌سازی و تست قبل از Release است.


## قابلیت‌های حرفه‌ای جدید

- دانلود چندبخشی واقعی تا 16 اتصال با Resume هر بخش
- Smart Segments بر اساس حجم فایل و پشتیبانی Range
- Site Profiles برای Header، Cookie، Referer، User-Agent، پوشه و Segment اختصاصی
- مرورگر داخلی با Media Detector برای لینک‌های مستقیم
- Share هوشمند لینک‌های مستقیم و صفحات X/Reddit
- Preview قبل از دانلود: نام فایل، حجم، MIME و Resume/Range
- Duplicate Manager: تغییر نام، جایگزینی، رد یا ادامه
- پوشه سفارشی برای هر دانلود
- SHA-256 اختیاری و بررسی صحت فایل
- Backup/Restore تنظیمات، پروفایل‌ها و تاریخچه
- Home Screen Widget با نمایش سرعت و Pause/Resume
- Network Profiles: متعادل، Wi-Fi سریع، صرفه‌جویی دیتا
- Completion Actions و Share فایل
- Torrent/Magnet به‌صورت ماژول اختیاری، بدون فهرست محتوای آماده
- لوگوی آبی روبانی تندرو در اپ، Launcher و Splash

> دانلود محتوای شبکه‌های اجتماعی فقط برای لینک‌های مستقیم و محتوایی است که کاربر مجاز به دریافت آن است؛ تندرو ابزار دورزدن DRM یا محدودیت‌های سرویس‌ها نیست.
