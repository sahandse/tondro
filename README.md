# تندرو (Tondro)

مدیر دانلود فارسی، سریع و مینیمال برای اندروید با Flutter.

## وضعیت
پروژه در حال توسعه است.

## هدف نسخه اول
- دانلود HTTP/HTTPS
- توقف و ادامه دانلود
- صف دانلودها
- چند دانلود هم‌زمان
- محدودیت سرعت
- زمان‌بندی دانلود
- تشخیص لینک کلیپ‌بورد
- تاریخچه دانلود
- دسته‌بندی فایل‌ها
- مدیریت فایل دانلودشده
- اعلان پیشرفت
- تم روشن/تیره

> هیچ داده‌ی دمو یا تستی در نسخه نهایی نمایش داده نمی‌شود.
